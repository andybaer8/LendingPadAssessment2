Summary of Changes
Duplicate Handling: Added logic to check for existing records when trying to create new ones.

User Update (Task 2): Refactored the Update method to validate inputs at the very beginning. This ensures the update fails fast if the Email or Name is null, preventing a partial state where some fields are updated but others aren't. Also updated the exception text to include the email.

Tagging: Implemented the "Find Users by Tag" feature. To support this, I added an Analyzed Field Index to the UsersListIndex and used a .WhereEquals clause in the repository.

New Modules: Scaffolded out the full stack for Product, Order, and LineItem (Models, Repositories, and Controllers). I followed the existing User architecture to keep the data pipelines and file structures consistent.
